# Альфа-Дент — Mini App + Telegram-бот с данными акций

Пакет включает обновлённый интерфейс Mini App, API, фотографии врачей, общий каталог 10 предложений из файла клиники «Акции- 2026.xlsx» и бота с тем же каталогом.

## Установка
1. Сделайте резервную копию текущего репозитория/сервера.
2. Распакуйте содержимое архива поверх проекта, сохранив структуру каталогов. `bot_telegram.py` заменяет прежний файл бота; проверьте и объедините локальные изменения до замены.
3. В начале `bot_telegram.py` вставьте НОВЫЙ токен Telegram, НОВЫЙ Bitrix24 webhook и рабочий SOCKS5. Старые ключи/прокси были раскрыты; их нужно отозвать и заменить. Значения допускается передавать через переменные окружения, но отдельный `.env` в архив не включён.
4. Оставлен код авторизации 1234, как просил заказчик. Автоматическая SMS-отправка не реализована.
5. Установите зависимости из `requirements.txt`, запустите API и бота, проверьте логи и `/health`.

## Акции
Mini App берёт карточки из `web/assets/promotions.json`. Telegram-бот читает этот же JSON: список → подробная карточка → «Записаться по акции». Название выбранной акции добавляется к заявке CRM.

## Важно
Заявки из Mini App/бота попадают в Bitrix24 как запросы на запись. Реальное бронирование слота, список свободных интервалов, личные визиты и перенос/отмена не работают без интеграции с МИС «Инфоклиника». В UI удалены фиктивные датированные сетки — клиент вводит предпочтительное время, которое должен подтвердить администратор.

Подробная сверка клиентских доработок и список недостающих интеграций: `INTEGRATION_GAPS_AND_TZ_STATUS.md`.
