# Проверка выкладки Mini App + бота

1. В `bot_telegram.py` задать новый Telegram token, Bitrix24 webhook и рабочий SOCKS5 прокси. Старые значения раскрыты и должны быть заменены.
2. Проверить наличие `web/assets/promotions.json` на сервере. И Mini App, и бот читают этот один файл.
3. Проверить синтаксис: `python -m py_compile bot_telegram.py webapp_api.py`; JavaScript Mini App проверяется через `node --check` после извлечения `<script>`.
4. Открыть `/health`; `crm_configured` должен быть `true`.
5. Через Telegram открыть Mini App, открыть «Акции», открыть каждую карточку, нажать «Записаться по акции» и отправить тестовую заявку. Проверить, что заголовок/комментарий лида в Bitrix24 содержит название акции.
6. В боте проверить `Акции → карточка → Записаться по акции`; после ввода кода 1234 пройти выбор типа записи и проверить поле «Акция» в заявке CRM.
7. Проверить форму администратора и экстренное обращение в реальной CRM.

Ожидаемое ограничение: дата/время в форме — предпочтения, а не свободные интервалы. Реальные интервалы и список визитов требуют интеграции с МИС «Инфоклиника». SMS-провайдер не подключён; код 1234 оставлен временно по запросу.
