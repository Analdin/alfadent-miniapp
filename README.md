# AlfaDent — legacy copy (не использовать для новой установки)

Этот репозиторий — прежняя копия Telegram-бота, Mini App и API, созданная до переноса на собственный VPS.

**Актуальный исходный код находится здесь:**
- [Mini App + FastAPI + Telegram](https://github.com/Analdin/mini-app_main)
- [MAX bot](https://github.com/Analdin/alfa-dent_max)

Для новой установки клонируйте только эти два репозитория. Не запускайте одновременно API из этого legacy-репозитория и API из `mini-app_main`: у них разные версии кода и это может привести к рассинхронизации авторизации/базы данных.

Старый Render service не отключайте до успешного переключения домена и проверки Telegram/MAX на VPS. После переключения этот репозиторий можно оставить как архив или удалить вручную.

**Безопасность:** более ранние коммиты этого репозитория содержали встроенные значения, похожие на токены бота, Bitrix24 webhook и proxy credentials. Не используйте эти значения повторно. Их нужно заменить в кабинетах соответствующих сервисов; удаление текущего файла не удаляет значения из истории Git.

Состав врачей, промо-материалы и актуальный интерфейс поддерживаются в `mini-app_main`. Изменения в этом архиве больше не принимаются.
