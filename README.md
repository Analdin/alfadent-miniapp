# АльфаДент: существующий Telegram-бот + Mini App

Этот пакет объединяет чат-бот из `bot_telegram.py` с интерфейсом `web/miniapp.html` и небольшим API, который направляет заявки из Mini App в текущую Bitrix24-логику. Прежние обработчики бота (создание заявки из чата, экстренные обращения, меню, список врачей, смены администраторов и резервное сохранение) сохранены.

## Что подключено

- В меню бота и сообщении авторизации добавлена кнопка `Открыть приложение клиники` (Telegram Web App); она появится рабочей только если `WEBAPP_URL` указывает на публичный HTTPS URL.
- Mini App содержит главную, врачей, услуги, экстренную помощь, акции, визиты, информацию о клинике, отзывы, рекомендации, профиль и сценарий записи.
- Формы заявки и обращения в Mini App используют `Telegram.WebApp.initData`, сервер проверяет HMAC-подпись Telegram и срок действия данных перед CRM-записью.
- Заявка на приём создаёт лид в Bitrix24 через функцию из существующего бота; пользователю явно сообщается, что слот не забронирован и администратор должен подтвердить время.
- Сообщение администратору создаёт отдельный CRM-лид через тот же Bitrix24 webhook. Экстренный текст помечается в заголовке.
- Секреты не вшиты в код. Задаются через `.env`.

## Что ещё не подключено и не должно считаться готовым

- МИС «Инфоклиника»: свободные слоты, реальные визиты, перенос и отмена пока не подключены.
- SMS/OTP по-настоящему не подключён. В коде безопасное значение по умолчанию — `AUTH_MODE=sms_not_configured`; в `.env.example` выставлен `AUTH_MODE=demo`, чтобы можно было проверить прототип. Этот режим и код `1234` разрешены только для изолированного теста, не для пациентов.
- `assignedById` в CRM и списки `ADMIN_IDS` нужно проверить по порталу заказчика; эта же логика используется существующим ботом.
- Содержание карточек врачей, фото, акции, цены и внешние ссылки в Mini App должны быть утверждены клиникой.
- Экраны «Мои визиты» и профиль пока демонстрационные; API не возвращает историю пациента.
- Перед реальной эксплуатацией нужен тест в копии Bitrix24, проверка требований к персональным данным и согласование текста согласия.

## Установка

1. Скопируйте содержимое пакета на сервер в отдельную папку.
2. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. Создайте `.env` на основе `.env.example`. Замените `TELEGRAM_TOKEN` на **новый** токен BotFather, укажите новый Bitrix24 webhook, ID администраторов и `WEBAPP_URL`.
4. Разместите `web/miniapp.html` и каталог `web/assets/` так, чтобы API раздавал страницу по `https://YOUR_DOMAIN/miniapp.html`. Сам API нужно разместить за HTTPS reverse proxy. Пример: nginx проксирует домен целиком на `127.0.0.1:8001`; маршрут `/api/*` обрабатывается API, `/assets/*` выдаёт файлы Mini App. `bot_telegram.py` запускается отдельным systemd-сервисом, также с тем же `.env`.
5. Запустите API для проверки:

   ```bash
   set -a; source .env; set +a
   python webapp_api.py
   ```

   Затем в другом терминале запустите бота:

   ```bash
   set -a; source .env; set +a
   python bot_telegram.py
   ```

6. Проверьте `https://YOUR_DOMAIN/health`, затем откройте бота в личном чате и нажмите кнопку Mini App.

Не используйте `file://` и не открывайте Mini App через HTTP: Telegram требует HTTPS для Web App URL.

## Очень важно про секреты

В исходном файле, который был загружен для объединения, токен Telegram и URL вебхука Bitrix24 находились прямо в коде. Перед развёртыванием отзовите старый токен через BotFather и создайте новый webhook в Bitrix24. Не отправляйте эти значения в чат и не публикуйте `.env`.

## Файлы

- `bot_telegram.py` — существующий бот с добавленной кнопкой Mini App.
- `webapp_api.py` — API для защищённой приёма данных Mini App и создания лидов.
- `web/miniapp.html` — интерфейс Mini App.
- `web/assets/` — картинки для карточек и обложек.
- `preview/index.html` — локальный обзорный стенд «чат + Mini App» (не запускайте его как боевую страницу; отправка в нём демонстрационная).
- `.env.example` — шаблон переменных окружения без секретов.
