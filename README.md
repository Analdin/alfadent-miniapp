# Альфа-Дент — Telegram-бот и общий Mini App

Этот репозиторий содержит Telegram-бота, общий Mini App и API, который проверяет подписи запуска Telegram и MAX. Mini App обслуживается по существующему адресу Render.

## Состав
- `bot_telegram.py` — Telegram-бот.
- `webapp_api.py` — FastAPI для Mini App; поддерживает проверку Telegram и MAX WebApp initData.
- `web/miniapp.html` и `web/assets/` — интерфейс, фотографии клиники/врачей и каталог акций.
- `requirements.txt` — зависимости API и Telegram-бота.

## Развёртывание Mini App API
Команда запуска для Render/сервера (если именно так настроен текущий сервис):

```bash
uvicorn webapp_api:app --host 0.0.0.0 --port $PORT
```

Путь проверки состояния: `/health`. Для запуска Telegram-бота отдельно используйте `python bot_telegram.py`. Установите зависимости: `pip install -r requirements.txt`.

## Переменные окружения
Смотрите `.env.example`. Настоящие токены и Bitrix24 webhook задаются только в настройках сервиса или приватной конфигурации. Не добавляйте `.env` в Git.

## Важно перед production
- В исходном проекте используется демонстрационная авторизация `1234` только при явно включённом `AUTH_MODE=demo`; SMS-провайдер не подключён. Для эксплуатации оставляйте `AUTH_MODE=sms_not_configured`, пока не будет реализована и проверена отправка OTP через выбранного провайдера.
- Интеграция с МИС «Инфоклиника» не подтверждена: приложение создаёт обращения/лиды, а не бронирует реальные слоты.
- Для MAX API необходимо задать `MAX_BOT_TOKEN`, совпадающий с токеном действующего MAX-бота.
- Состав врачей в списках синхронизирован с текущим списком за исключением девяти специалистов, отмеченных клиникой. Из активного исходного списка дополнительно удалены Широков Игорь Валентинович и Оганесян Тигран Сергеевич; остальные семь отмеченных фамилий в активном списке уже отсутствовали.
